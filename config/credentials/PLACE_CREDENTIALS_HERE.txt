⚠️  ВАЖНО: Замените этот файл на реальный credentials.json

1. Откройте Google Cloud Console:
   https://console.cloud.google.com/

2. Перейдите в: APIs & Services > Credentials

3. Создайте OAuth 2.0 Client ID:
   - Application type: Web application или Desktop application
   - Authorized redirect URIs: http://localhost:8080/oauth/callback

4. Скачайте JSON файл

5. Сохраните его как: credentials.json (в этой директории)

6. Убедитесь, что файл имеет структуру:
   {
     "installed": {
       "client_id": "ваш_реальный_client_id",
       "client_secret": "ваш_реальный_client_secret",
       "redirect_uris": ["http://localhost:8080/oauth/callback"]
     }
   }
   
   или
   
   {
     "web": {
       "client_id": "ваш_реальный_client_id",
       "client_secret": "ваш_реальный_client_secret",
       "redirect_uris": ["http://localhost:8080/oauth/callback"]
     }
   }

7. После сохранения файла перезапустите контейнер:
   make down && make up
